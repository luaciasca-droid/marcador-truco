# Marcador de Truco

Marcador de pontos de truco (até 12) com duplas e ranking geral salvo na nuvem (Firebase Firestore).

- Abra no iPhone pelo Safari e use **Compartilhar → Adicionar à Tela de Início**.
- `firestore.rules`: regras de acesso do banco (cole no console do Firebase em Firestore → Rules).
